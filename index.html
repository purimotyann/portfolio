学食混雑度リアルタイム共有アプリ

食堂の混み具合やメニューの販売状況を、ブラウザから確認できるWebアプリです。現在の利用人数と混雑度に加えて、10分後・20分後の混雑予測も確認できます。食堂へ行く前の状況確認や、管理者による食堂情報の更新に使えます。

HTML / CSS JavaScript Java Python GitHub Pages

✨ 主な機能

  • 混雑状況の確認： 現在人数・利用率・混雑度・最終更新日時を表示
  • AIによる人数計測： カメラ映像から人物を検出し、利用人数を自動計測
  • 混雑予測： 計測履歴から10分後・20分後の人数を推定
  • メニューの販売状況： カレーライス・ラーメン・唐揚げ定食・日替わり定食の販売中／売り切れを表示
  • お知らせ： 食堂からの案内を表示
  • 自動更新： 新しいデータを自動で取得（3分以上更新停止時は警告表示）
  • 管理者機能： ログインした管理者が人数・販売状況・お知らせを更新・保存可能

📊 混雑度の見方（定員40名基準）

利用人数から利用率を計算し、3段階で混み具合を表示します。

30%未満：🟢 空いている 30%以上・70%未満：🟡 普通 70%以上：🔴 混雑

💡 使い方

混雑表示画面を開くと、ログインせずに混雑状況・予測・メニュー・お知らせを確認できます。画面の情報は自動で更新されます。
